# 152d — AI assistant

Rules: `docs/tasks/152-ui-common.md`. Feature `ai` (views + `ai.css`, including the billing
admin panel and the workspace sheet). e2e: `node tools/e2e/run.mjs ai`.

## What the area essentially is

Conversations with an assistant: like chat, but the answer is long, rich text that is read
more than skimmed (ChatGPT/Claude app pattern).

## List pane (collection width)

`PaneHeader` AI with `IconButton` 新对话 (`plus`) and `IconButton` 工作区 (`folder`).
`PaneTools`: `SearchField` 搜索标题和标签. Rows (`ai.list`): title, hint = tags or last
update; leading small `sparkles` tile; a running indicator (spinning `loading` icon as
`titleSuffix`) and unread badge. Credits as a quiet footer strip at the bottom of the list
pane: two thin `Progress` bars labelled 今日 n% · 本周 n% and 可用额度.

## Conversation (content)

- `PaneHeader`: title (`ai.conversation.title`), subtitle tags; actions `IconButton`
  标题与标签 (`edit`), `Menu` ⋯ for other actions.
- Messages (`ai.message`, `data-role`): a centred column max 760 px. User messages: a
  right-aligned `--raised` block, radius 12, max 80%. Assistant messages: full-width plain
  text, no bubble, small `sparkles` mark at the left of the first line, rich text with
  `--lh-read`, code blocks on `--raised` with mono font, tables bordered hairline. Message
  actions (从此创建分支, copy) appear as small icon buttons under the message on hover/tap;
  keep the accessible names. Status lines (已停止, 失败 with partial text) as `Mark`/muted
  text under the message.
- Streaming: a subtle caret/pulse at the end; 停止生成 replaces 发送 in the composer.
- Composer: `SharedComposer` in the footer, the column width; tools: 图片; attached images
  as 56 px thumbnails chips with remove; the reason it cannot send shown persistently as a
  muted line above the field (`此操作需要连接服务器` must be visible text while offline).
- Empty conversation: centred greeting `有什么可以帮你？` with the composer.
- Nothing selected: `EmptyPane` `ai`, hint 开始一段新对话.

## Workspace sheet

`Sheet` 工作区: folder/file rows with icons, path breadcrumbs, file preview (预览文件) and
the source editor (`ai.workspace.editor`, mono font, 编辑源码) with footer save/cancel;
delete confirms naming the path.

## Billing panel (admin workbench extension)

`ai.billing` scroll container: summary tiles (grid, like the learning stats), the daily
chart (`ai.billing.chart`; bars in accent, hairline axes, muted labels), policy form in a
`Group` with `Field`s and a primary save; accounts table via `DataGrid`; 分配额度 dialog.
